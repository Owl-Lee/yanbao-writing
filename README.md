# Writing by Yanbao Li

Personal essays and notes published at [writing.yanbaoli.me](https://writing.yanbaoli.me).

## Publish a new article

1. Copy a Markdown file into `_posts/`.
2. Name it `YYYY-MM-DD-short-title.md`.
3. Add the front matter shown below, then write normally in Markdown.

```yaml
---
layout: post
title: "Article title"
excerpt: "A one-sentence description for the home page."
date: 2026-09-04 12:00:00 -0400
category: 随笔
tags: [生活, 观察]
reading_time: 4
---
```

Pushing to the default branch publishes through GitHub Pages.
